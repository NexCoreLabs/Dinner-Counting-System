# 🤖 واتساب بوت وجبات السكن — SQU

نظام أوتوماتيكي لإحصاء عدد طالبات السكن اللواتي سيتناولن العشاء في نهاية الأسبوع.
يعمل مباشرة من واتساب عن طريق مسح QR — بدون أي تسجيل أو رسوم.

---

## ⚙️ خطوات التشغيل

### 1. تثبيت Node.js
تأكد إن عندك Node.js مثبت:
```bash
node --version  # يجب أن يكون v18 أو أحدث
```

### 2. تثبيت المكتبات
```bash
npm install
```

### 3. إعداد ملف البيئة
```bash
cp .env.example .env
```
الملف جاهز بالإعدادات الافتراضية.

### 4. تشغيل البوت
```bash
npm start
```

### 5. مسح QR Code
بعد التشغيل يظهر QR في التيرمنال:
1. افتح واتساب على هاتفك
2. اذهب إلى ⋮ > الأجهزة المرتبطة > ربط جهاز
3. امسح الـ QR
4. ✅ البوت يعمل الآن!

> **ملاحظة:** بعد أول مسح، الجلسة تُحفظ تلقائياً ولا تحتاج تمسح مرة ثانية.

## ⏰ الجدول الزمني التلقائي

| الوقت | الحدث |
|-------|-------|
| أربعاء 10:00 ص | إرسال الاستبيان لجميع الطالبات |
| أربعاء 8:00 م | تذكير للطالبات اللواتي لم يردن |
| خميس 10:00 ص | إرسال التقرير النهائي للمشرف |

## 📡 API للإدارة

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| POST | `/api/register` | تسجيل طالبة جديدة |
| GET  | `/api/report` | التقرير الأسبوعي |
| GET  | `/api/students` | قائمة الطالبات |
| POST | `/api/test/send-poll` | اختبار إرسال الاستبيان |
| POST | `/api/test/send-reminders` | اختبار التذكيرات |
| GET  | `/admin` | صفحة لوحة تحكم الإدارة |
